# FC Games 红白机游戏厅

浏览器单机游戏大厅。首款游戏为《超级马里奥兄弟》，已开放 World 1-1 和 1-2，使用项目附带的 Jingchuanchu Engine 0.5.0。

## 本地运行

在项目根目录使用 Node.js 22.12 或更高版本运行以下命令。

```sh
npm ci
npm run dev
```

打开终端显示的地址，在大厅选择游戏，再点击画面内的「开始游戏」。也可以直接进入 `#/play/smb`。1-1 的旗杆、进城和计分动画结束后自动进入 1-2，继续使用本局生命、分数、金币和体型。画面右下方可切换全屏，网页内和全屏均采用 16:15 比例。游玩时用方向键或 A / D 移动，Space 或 Z 跳跃，Shift 或 X 冲刺，向下键进入竖管，向右走进横管，大马里奥按住向下键可蹲伏，取得火力花后用 C 或 X 发射火球。助跑后起跳可以跳得更高、更远，按住跳跃键可延长上升。Esc 暂停或退出全屏，开始游戏时会尝试播放音乐，点「开启声音」可启用音乐与音效。

游戏画面右下方的「键位设置」可单独调整本游戏的按键。游玩时可以从画面右下方或暂停菜单选择「保存并退出」，把当前关卡、生命、分数、金币与体型保存到浏览器后返回大厅。再次进入游戏，在标题菜单选择「继续存档」，即可带着这些状态从保存关卡的起点继续。

```sh
npm test        # 关卡和玩法规则回归
npm run build   # 检查引擎组件、类型并构建静态文件
npm run preview # 预览 dist
```

将 `dist/` 放到任意静态 HTTP 站点即可运行。游戏使用 hash 路由，部署到子目录时保留构建产物的目录结构。
